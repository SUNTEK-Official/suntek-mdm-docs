# SUNTEK MDM Management Console Overview

The SUNTEK MDM Management Console enables remote fleet monitoring, silent APK deployment, kiosk lockdown, and policy compliance for global POS and kiosk deployments.

1. Refer to [`MDM-Administrator-User-Guide-v4.22.pdf`](../pdf/MDM-Administrator-User-Guide-v4.22.pdf) for server enrollment URLs, role permissions, and OTA scheduling.
2. Provisioning endpoints and tenant credentials are delivered securely per customer account via SUNTEK Enterprise Support (`support@suntekai.com`).
